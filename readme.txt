A lightweight frontend author dashboard with post submission, draft management, and GitHub update checks.

== Description ==

Frontend Post Dashboard allows authorized authors and users to create, draft, edit, and manage blog posts directly from the frontend without accessing the WordPress admin dashboard.

= Key Features =
* Full Rich-Text Editor with TinyMCE formatting.
* Theme Color Integration from modern block themes and classic themes.
* Responsive video containers to prevent layout breaking.
* Live sorting of posts by Title, Status, and Date.
* Quick switch between Editor and "My Articles".

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/frontend-post-dashboard` directory.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Use the shortcode `[frontend_post_dashboard]` on any page.
